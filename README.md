# SSC CGL Practice CBT

Unofficial practice site. Anime-white UI.

## Upload to GitHub
1. Create a new repository (or open an existing one).
2. Upload **only** `index.html` and `README.md` from this folder.
3. GitHub → Settings → Pages → Source: Deploy from branch → `main` / root.
4. Open `https://YOUR-USERNAME.github.io/REPO-NAME/`

Or double-click `index.html` locally in Chrome.
