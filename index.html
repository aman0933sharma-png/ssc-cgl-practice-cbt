General Instructions — CGL Tier-I

  1. Total duration is 60 minutes. From CGL 2026, each of the four parts is locked to 15 minutes. Unused time is not carried forward.
  2. The paper has 100 objective questions: Part A Reasoning (25), Part B General Awareness (25), Part C Quantitative Aptitude (25), Part D English Comprehension (25).
  3. Each correct answer = +2. Each wrong answer = −0.50. Unattempted = 0.
  4. Questions are previous-year pattern items. A new random paper is generated every time you start.
  5. Click the radio button beside an option to select it. Then press Save and Next.
  6. Mark for Review parks a question (yellow / purple) so you can return within the same section’s 15 minutes.
  7. When a section timer hits 00:00 the interface moves you to the next part automatically.
